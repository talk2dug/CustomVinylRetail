ARA — American Rally Association

Visual Package requiredRear windshield decal (2025+)

ARA publishes an official Visual Package / Vehicle Identification Standard that specifies door number placards, windshield banners, and other decals. Placements are diagrammed and may be adjusted slightly for body shape.

SCCA — Sports Car Club of America

GCR governs Road RacingNumbers/letters required

The SCCA General Competition Rules (GCR) and program pages define required decals and numbers. Solo/TT also specify number & class visibility. Sponsor decals are required at National events.

UseTypical size / ruleNotes & Source
National sponsor decalsRequired on each side and front; upright & prominent.SCCA Vehicle Identification
Solo (Rule 3.7) car numbers≥ 6" high, ≥ 3/4" stroke, high contrast; class letters on both sides.SCCA Solo reminder

Common club‑racing baseline used by many shops: Door numbers ≈ 10" high, hood/rear ≈ 8", class letters ≈ 4", driver name ≈ 2". Confirm against event/series rules.

NASA — National Auto Sport Association (selected series examples)

CCRs + Series Rules

NASA uses the Club Codes & Regulations (CCR) plus series‑specific rules. Sizes below come from 2025 series rulebooks.

SeriesMust‑have decals / IDsExplicit sizes from rulesSource
Spec E30 Side, hood/front, and rear numbers; “SE30/Spec E30” class ID; driver last name. Side numbers ≥ 12" high (stroke 1.5–3"). Hood/rear numbers ≥ 5". Class ID letters/numbers ≥ 3" with ≥ 0.5" stroke. Driver name ≈ 3" on windows + lower passenger windshield. 2025 Spec E30 Rules (PDF)
Spec3 Series/NASA decals (as required). Class ID near side numbers. Driver last name on windows + windshield. Class “SPEC3” ≥ 3" tall. Driver last name 3" tall. 2025 Spec3 Rules (PDF)
944 Spec Required sponsor & series decals: Hoosier, HAWK, 944 SPEC, NASA (plus any CCR‑required). Permanent affixing required; sizes/locations per series & CCR (check event supps). 2025 944 Spec Rules (PDF)

Disclaimers

  • This page summarizes public 2025 sources; rules can change mid‑season via bulletins. Verify before production.
  • Event Supplemental Regulations (supps) can add or override placement/size requirements.
  • For ARA, always use their current downloadable Visual Package template for exact geometry.
